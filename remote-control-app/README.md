# Remote Control (Android ↔ Android)

같은 Wi-Fi 네트워크에 있는 두 안드로이드 기기를 서로 연결해, 한 기기(호스트)의 화면을 다른 기기(컨트롤러)에서
보고 조작할 수 있게 해주는 앱입니다. 하나의 앱이 호스트 역할과 컨트롤러 역할을 모두 수행할 수 있습니다.

## 동작 방식

- **호스트**: `MediaProjection`으로 화면을 캡처해 `MediaCodec`(H.264)으로 인코딩하고, TCP 소켓으로
  스트리밍합니다. 컨트롤러가 보낸 터치 입력은 `AccessibilityService`의 `dispatchGesture`를 통해 실제
  제스처로 재생됩니다.
- **컨트롤러**: 호스트의 IP 주소·포트·PIN을 입력해 연결하면, 수신한 H.264 스트림을 `MediaCodec` 디코더로
  복호화해 화면에 그리고, 화면 터치를 정규화된 좌표로 변환해 호스트로 전송합니다.
- **페어링**: 호스트가 세션마다 새로운 6자리 PIN을 생성해 화면에 표시합니다. 컨트롤러는 이 PIN을 알아야만
  연결할 수 있습니다.

## 보안/동의 관련 설계

원격 제어는 오남용 가능성이 있는 기능이므로, 다음을 의도적으로 지켰습니다.

- 화면 캡처가 켜져 있는 동안에는 안드로이드 시스템이 강제로 지속 알림(포그라운드 서비스 알림)을 표시합니다.
  이 알림은 앱이 숨길 수 없습니다.
- 입력 주입에 필요한 접근성 서비스는 사용자가 **설정 > 손쉬운 사용**에서 직접 켜야만 동작합니다.
- 매 세션 새로 생성되는 PIN 없이는 컨트롤러가 호스트에 연결할 수 없습니다.

> 현재 버전은 신뢰할 수 있는 같은 로컬 네트워크에서의 사용을 전제로 하며, 소켓 통신 자체는 암호화되어
> 있지 않습니다(전송 구간 암호화는 후속 작업입니다). 공용 Wi-Fi 등 신뢰할 수 없는 네트워크에서의 사용은
> 권장하지 않습니다.

## 빌드

```bash
cd remote-control-app
./gradlew assembleDebug
```

## 사용법

1. 호스트가 될 기기에서 앱을 열고 **이 기기를 제어받기(호스트)** 선택 → 화면 공유 시작 → 화면 캡처 권한 허용.
2. 손쉬운 사용 경고가 보이면 안내에 따라 접근성 서비스를 켭니다.
3. 화면에 표시된 IP 주소·포트·PIN을 컨트롤러 기기에 입력합니다.
4. 컨트롤러가 될 기기에서 **다른 기기 제어하기(컨트롤러)** 선택 → IP/포트/PIN 입력 → 연결.

## 알려진 제약 (다음 단계)

- 같은 로컬 네트워크(Wi-Fi)에서만 동작합니다. 인터넷 너머 원격 연결(NAT 통과/릴레이 서버)은 아직 없습니다.
- 전송 구간 암호화(TLS)가 없습니다.
- 다중 터치(핀치/멀티 포인터) 제스처는 아직 지원하지 않습니다(단일 포인터 탭/드래그만 지원).
- 안드로이드-PC, PC-PC 조합은 아직 구현되지 않았습니다.
